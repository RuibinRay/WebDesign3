Shot sheet

Every picture and film the Racimo site needs, with what has been made so far. Each prompt carries the same look blocks word for word, and every shot that shows a bag takes the drawn pack as its reference image, so the label in the photo is the real design.

Automatic (Higgsfield CLI)

  1. Open refs.html and press Save the four references. Free, and only needed once.
  2. node higgsfield/generate.mjs prints the plan, the price of every job and the balance. It spends nothing.
  3. node higgsfield/generate.mjs --go makes stage 1, then stage 2, then the films, then runs the optimiser.
  4. One at a time or by group: node higgsfield/generate.mjs verde-bag --go · images --go · films --go. Re-roll with --force.

By hand (Higgsfield app)

  1. Copy a prompt below. Use the model and aspect it shows, and attach the reference image it names.
  2. Save the download as higgsfield/renders/<id>.png (films: .mp4).
  3. Run npm install once, then node higgsfield/optimize.mjs, and reload the site.
